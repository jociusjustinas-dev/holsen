# Fictional team assets — design review only

Generated 2026-09-08 using the built-in imagegen tool, not the CLI. Names, roles and portraits are fictional examples requested for layout review, not real Holsen personnel. At the user's request, the disclaimer is not displayed in the UI; fictional status is recorded in an HTML comment and this documentation. Draft/noindex status and the data-validation="required" release guard remain until replaced with client-approved real profiles and publication rights.

The source portraits are retained in the generation output directory. Project JPEG copies are 800 × 1200, quality 82; only size/format conversion was applied. Existing Vector.svg and Group 2.svg masks provide the cutouts in CSS, without changing the source artwork.
